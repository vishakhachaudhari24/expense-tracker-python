# Expense Tracker (Python + SQLite)

A simple console-based Expense Tracker built using Python and SQLite.
It allows users to add, view, and analyze expenses category-wise.

## Features
- Add expenses (amount, category, date, note)
- View all expenses
- Category-wise expense analysis
- Data stored permanently using SQLite

## Tech Stack
- Python
- SQLite
- SQL queries

## How to Run
1. Clone the repository
2. Run `python main.py`
3. Follow the menu options

## Future Improvements
- Monthly reports
- Export to CSV
- GUI using Tkinter
